# 3D 打印分析

适用于打印前评估、打印过程观察、故障定位和质量优化。先确认打印机、喷嘴、材料、切片文件、照片与当前问题是否对应同一次试印；已有切片工程时优先读取实际设置和逐层预览。无法读取文件或视频时明确说明，不把推测说成已检查结果。

## 按需装载能力

- 开始时发现当前环境可用的 3D 打印技能和工具，按任务需要**读取**相关 `SKILL.md`。本次曾装载 `3d-printer-on-demand:design-check-before-printing`：有 STL、3MF、STEP 或 OBJ 文件且需要模型可打印性检查时可用；照片和切片的现场故障分析仍需对照用户的实物与逐层预览。询价才使用报价技能。
- 区分“已发现”“已读取／装载”“已安装”“工具调用成功”。技能文件已读不等于连接服务可用；检查接口返回错误也不等于模型有错。先核对本机文件是否可读及工具实际返回，不把失败臆断为中文路径问题。
- 需要新能力时，先查现有插件／技能及适用范围；若用户要求安装且目标明确，按当前环境的安装工具或本仓库 README 的关联安装方式操作，检查目标是否已有同名技能，验证实际安装状态。只有读取资料的请求不自动授权安装、改用户级配置或发布。本仓库文件保存也不等于已安装；向用户如实说明当前状态。

## 从证据定位关键位置

1. 对照切片预览、打印中和停止后的照片，找出第一处与预期路径不一致的层高与位置。后续的“炒面”常是结果，不直接当成原因。
2. 分清模型本体、树支撑、支撑底脚、brim 和 skirt。实物仍在板上的底脚，不能说成整根连 brim 掀起；模型完好也不能证明支撑顶端有效。
3. 对疑似悬空处，从第一条起印路径往下逐层检查：是否有支撑、支撑顶端是否位于路径正下方、接触面积是否足够、支撑是否连续连到板或模型。切片的支撑 Z 间距不等于漏支撑。
4. 如支撑底脚脱板，检查局部首层、板面和底脚面积；如底脚留在板上而上部消失，检查枝干断点与喷嘴碰撞；如模型局部脱落，检查其最初起印与连接截面。不要仅凭结束后的照片断言具体碰撞机制。
5. 若补支撑后仍在相近高度重复脱落，把它当作对原归因的反证。比较新切片的实际支撑路径、支撑顶面、脱落件两端及模型连接断面，再判断是支撑接触、模型连接还是喷嘴碰撞；不要继续堆叠未经验证的参数调整。

## 给出修改与复查

- 对预览中确认的缺支撑位置，在切片器的准备页选模型并使用支撑绘制，标出悬空起印面的下侧；重新切片，确认实际生成的支撑接到目标区域。自动与手动模式行为随切片器和版本变化，切换为手动后须检查其他原本自动生成的支撑是否仍在。
- 根据已定位的问题，只改少数相关变量。支撑速度、分支直径、角度、外墙层数、首层扩展与模型 brim 各有不同作用；局部悬空不能靠放大 brim 修复。现场试印数值不得写成通用推荐或已验证解法。
- 交付时分别说明观察、可能的原因、还不能确定之处，以及下一次试印应观察的关键层高或位置。验证标准随目标而定：例如支撑问题需确认目标处从第一层起有连续有效承托，并在真实试印中保持稳定。切片预览通过不等于打印成功。
- 多零件任务中仅一件失效时，可先暂停并确认松散物不会妨碍喷头，再按现场设备和软件的实际能力跳过该件。核对任务是否把各件保留为独立对象、选中的是否正是失败件；跳过未来路径不会移除已掉落的实体或散料。无法安全清理或确认路径时，不建议盲目恢复。具体入口和限制需按当前机型／软件版本核实。

打印导向建模的工作流和试错继续放在 `3dprinter/`，不混入 Blender 的通用建模与场景工作流；有独立触发场景时再设新入口。需要了解本次流程的已观察依据与未验证部分时，读取 [2026-11-01-figure-support-case.md](references/2026-11-01-figure-support-case.md)。
