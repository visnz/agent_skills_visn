# 人体结构参考：相机、骨架代理与 FK 适配

用于从人体结构图较准确地恢复静态大动作，或角色网格变形会干扰姿势判断的任务。文字意图摆姿势无需机械执行全部步骤。先明确主验收图；后补的标注图、生成多视图和侧面解释图作为辅助，除非用户改变主参考。

首次开始图片恢复/代理映射，或再次尝试旧方法前，先读 [历史案例](2026-11-08-proxy-fk-mapping.md) 的对应分支；遇到类似反例时核对旧条件，说明本次改变了什么。基础假设、辅助图与控制器拟合按任务需要选用，不要求普通摆姿势依次走完整套流程。

## 先建立相机比较基线

- 从骨盆横轴与人物朝前方向的投影关系估计水平观察方位，再结合腰胸到头、髋膝到脚的曲线、遮挡与上下表面可见度估计俯仰。人体可能扭腰、侧倾，单图通常不能唯一求出真实相机，记录当前假设。
- 普通透视人体参考可先试 30–50 mm 焦段；镜头、传感器尺寸、sensor fit、画幅、像素比例与 shift 一起决定投影，不能只写焦距。已有固定任务相机优先保留；正交或明显特殊透视按参考选择。
- 相机粗匹配完成后先固定水平角、俯仰和投影参数，建立可比较基线，再精调骨架。若新证据表明相机假设不成立，回到相机阶段，单独记录变更并重建对照，不能一边改相机一边把效果变化归因于骨架。后续若仅因角色比例不同需统一距离、构图或画幅，单独记录，保持同一角度并重新输出比较基线；不能靠换角度掩盖关节偏差。
- 尽早把必要参考复制到工作目录或打包进交付文件，避免持续依赖剪贴板临时路径。标明全幅、局部裁切与缩放；比较图保持可解释的尺度。

## 把图片变成可检查的目标

先记录原图像素坐标或归一化坐标、角色自身左右、可见性与置信度。至少覆盖骨盆、腰胸、颈根、头、双肩肘腕、双髋膝踝和足部方向；同时注明承重侧、交叉顺序、肘膝弯曲平面。表面标记、关节球外壳、内部旋转中心与手脚末端不能混为同一种关节点。

逐段处理：从骨盆开始，沿腰胸颈头及各肢体链先父后子。复杂恢复时逐段核对参考方向、父子关系、深度假设和调整后的端点投影、弯折平面及前后关系；简单任务可按一条骨链或一组相关关节检查。只在假设变化、关键分歧和阶段结果时向用户反馈，不要求每根骨骼都逐条汇报。不要直接猜一套三维坐标后用大量截图盲调。

用户希望先隔离大骨架时，建立独立场景的关节球/骨杆或简单骨架代理。先核对骨架，后映射到角色；不要提前创建服装形态键或重做权重。代理的同一姿势应能从任务相机与侧面/正面检查。

## 辅助多视图与坐标的使用边界

仅在辅助深度或结构判断确有收益、且工具可用并已获准时，才选择生成同姿势的正面、侧面、背面关节辅助图；不是所有姿势任务的前置步骤。提示词应固定主参考、解剖左右、关节编号、骨长关系、承重脚、交叉层次、肘膝朝向和相机方向；选择这条路线时先生成辅助图，再提取对应关节并保留输入与提示词；已有足够参考时直接使用，不为流程形式额外生成。

生成图允许比例差异，不能当作经过相机标定的真实多视图。不要为了让每张辅助图完全一致而偏离主参考；也不能把“主图优先”理解为允许其他视角出现明显反折、穿越或错误支撑。

可以标注坐标，但分清来源：

| 数据 | 含义 |
| --- | --- |
| 原图 `(u,v)`、图像尺寸 | 实际提取/人工标注的图像位置；注明遮挡与置信度 |
| 生成图中的格线、关节号 | 辅助定位；模型生成的数值不是测量结果 |
| 代理的 `(X,Y,Z)` | 建立骨架后计算的三维值；说明原点、轴向、单位和尺度假设 |
| 重投影偏差 | 当前骨架相对本次标注的差异；不等于相对真实人体的误差 |

存在三维骨架当然有帮助，但用户委托的正是图片恢复姿势时，不能要求用户先完成一个摆好的骨架作为前提。

## FK 与投影检查

这种静态逐骨参考匹配优先考虑 FK；用户指定 FK 时现场核对 IK/FK 开关的实际含义，不把某次 Rigify 的数值套到所有骨架。已有动作、约束、呼吸层和附件应分别保存与验证。几何求解可离线计算 FK 旋转目标，但最终控制器状态、位置和模式必须可继续编辑，不偷偷添加 IK 约束。

- 固定真实骨长，用主图投影和辅助深度约束求方向；不要为了降低像素误差拉伸骨骼。比较误差的同时列出最差关节、人物画面高度、标注置信度和未确定的深度关系，不套用本案例的数值阈值。
- 两段骨的末端可达不代表肘膝正确。检查肘膝位置、弯曲平面及前后层次；主图像素吻合时仍需多角度检查实际三维骨架。
- 由图像射线与父关节的定长球面求端点可能出现两个解，或根本不可达。不能只取距离上一姿势最近的解：它可能把手腕放到胸后。用朝前方向、遮挡、肢体顺序与侧视筛选；无合理解时回查父段、比例、标注及相机假设。
- 参数有效、脚底高度正常、保存重开成功，只能证明对应的工程状态；不能证明人体逻辑、主图还原或用户满意度。

## 从代理适配到角色

先定义骨骼语义对应、静止轴和父子层级，保留目标骨长、物体变换及附件。不要直接复制欧拉角，也不要只写会被约束覆盖的 DEF 骨矩阵。通过实际 FK/躯干控制器适配后，再用同角度检查角色的骨骼投影。

主图轮廓、解剖合理性和目标比例可能冲突。允许辅助图与角色比例有差异；明显冲突时说明偏差来源和取舍，保留可回退版本。把承重膝强行拉直可能破坏交叉腿轮廓，端点精确也可能引入错误轴向扭转，不能用一个角度或单一误差做决定。

静止状态网格正常、权重数值没变，不证明大幅屈曲时蒙皮正确。若出现袖口塌陷、膝部异常，分别检查控制骨、求值变形骨、权重覆盖、轴向扭转与修改器；在副本上才做已授权的修复试验。单凭某组缺失不能宣布已找到唯一根因。

用户明确以骨架交付并自行修权重时，完成骨架映射和对照，说明网格效果受现有蒙皮权重/变形映射影响、哪些尚未验证；保留原权重和服装，不再用形态键遮盖或继续追逐网格外观。它是范围内交付，不是完整视觉还原成功。

## 大骨架与局部细节分阶段

大骨架尚未确认时，先处理肩胯、肘膝、腕踝和支撑关系。用户要求分阶段、且尚未授权局部细节时，在大骨架确认后再询问是否继续双手双脚；获准后按目标截取手脚或其他关键接触部位的局部放大，分析实际需要的掌面、拇指、指节、脚掌等方向；四个手脚局部是历史案例的具体范围。已有明确细节授权时不重复询问。
