# Blender 角色摆动作

从用户当前选中的角色和当前工程出发，先判断动作想传达什么，再调整轮廓、重心和支撑。二维参考里的关节点可以辅助定位；用户说“自然”“慵懒”等观感要求时，还要看肩颈是否放松、肘是否有余量、手指是抓握还是轻搭，以及角色实际注视哪里。几何检查通过不等于姿态已获用户认可。

## 开始与边界

- 读取当前文件、未保存状态、活动/选中物体、其父子关系、绑定网格、隐藏角色、已有动作和形态键。用户更换选择或调整现场后重新读取，不用上一轮缓存的对象名和世界坐标覆盖新状态。
- 在修改前保存可恢复状态，尤其是用户尚未保存的姿势。只调整本次目标角色与必要的局部修形；保留其他角色、道具、摄像机和隐藏状态。若场景在操作期间变化，以最新现场为准，先核对再继续。
- 用户指定“从摄像机看”时，读取相机投影、画幅、世界矩阵和道具求值几何。优先在允许范围内摆角色；不要靠移动固定相机掩盖姿态问题。局部放大预览应标明裁切，不能代替全幅构图。
- 连接、多实例与社区技能装载遵循 [Blender 总入口](../blender-workflow/SKILL.md) 的适用规则；按任务选择基础和相关专题，不因为是角色就自动雕刻、重绑或制作动画。骨轴异常时先读 [骨轴前置检查](references/rig-axis-prerequisite.md)。

## 摆姿势的判断顺序

1. 从参考里提炼动作意图和几个画面锚点：头、肩、肘、掌根、道具边缘及视线。先对齐大轮廓和承重关系，再调整手指、袖口、裙摆。一次视觉反馈若指出整体情绪不对，回到头颈、肩线和手臂轮廓，别继续微调坐标。
2. 查真实骨骼层级与静止轴。导入骨架的锁骨可能挂在颈骨下；转头可能牵动肩，左右骨名也不保证与画面左右一致。骨盆、脊柱、头、肩、肘分开处理，保留弯曲余量。
3. 按实际骨长检查手脚目标是否可达。两段骨求肘/膝时，检查距离落在两骨长的可达区间内；碰到极限就调整身体、肩或接触点，不把求解器的截断目标当成已到达。骨骼关节到位后仍需检查求值网格。
4. 给手设置带方向的解剖参照：中指方向、食指至小指的横向、拇指所在侧，再决定掌面与前臂扭转。只对齐手的朝向、忽略横向正负，可能把拇指翻到脸的反侧；只扭腕而不检查前臂，可能把袖口拧坏。接触、坐姿修形和相机对照详见 [参考摆姿势与接触](references/camera-pose-and-contact.md)。
5. 少量关键视角迭代：任务相机全幅与局部、接触侧视，必要时补顶视或背面。数值检查、真实视口/渲染、用户的审美反馈分别记录。用户明确倾向自然感时，以放松程度和支撑可信度为优先，允许适当偏离参考。

## 完成标准

交付可继续编辑的骨架姿势，并说明保存位置或当前仅在内存中；需要静态接触修形时用可关闭、明确标注适用姿势的形态键。实际检查目标角色的画面轮廓、左右手/拇指、掌根与道具表面、相关服装穿插，及范围外对象的保留情况。用户要求保存时重开最终副本核对身份和关键状态；未测试动画、连续表面或美术满意度时不声称这些已经通过。

本技能依据 [课桌坐姿与云边倚靠案例](references/2026-10-27-seated-and-cloud-pose.md)。案例里的骨名、场景比例、参数和视觉结果只用于说明当时的取舍。
