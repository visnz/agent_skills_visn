# 2026-10-29—30：天空、涟漪、串珠与空气粒子实践

这是同一次对话中的实验与复盘，整理于 2026-10-31。依据保留下来的操作脚本、部分 JSON 结果、测试图和用户反馈。以下仅代表当时现场，不提供固定工程路径、对象名或调参预设。可复用方法见 [procedural-node-effects.md](procedural-node-effects.md)。

## 天空：可见度之外还有控制链

用户先要求星星分布/密度能调，再要求白天有星星。做法是复制旧组留备份，复用星星计算和渐变遮罩，提取星星发光叠加到白天/黄昏分支。

新增输入首次插到原输入中间，随后改为追加，以保持已有 `inputs[index]` 驱动路径的语义。另一次“可见度=1仍无星星”检查发现天空/云分支和昼夜值不符合目标，且从主材质驱动过来的星星缩放仍为较大值；最后修正主控实例，而不是只改被驱动端。

隔离图像对比的已保存结果：

| 对比 | 改变的像素数 |
| --- | ---: |
| 原白天 vs 新版可见度关闭 | 0 |
| 新版白天关闭 vs 开启 | 180 |
| 开启后改变密度 | 391 |
| 开启后改变分布 | 354 |
| 原夜晚 vs 新版夜晚 | 0 |
| 原云分支 vs 新版云分支 | 0 |

这些结果支持当时测试配置下的控制响应与分支保留，不证明所有星星设置或所有帧都已验证。

用户之后选中三条 Color Ramp，要求各加 HSV 并在外面调节。操作记录增加 3 个 HSV、9 个接口，枚举后重连输出消费者，并以中性默认值保留原色。随后将控制移入可折叠 Panel，检查 socket 顺序和原驱动。不能将“driver 有效”单独视为此类修改正确的依据。

## 曲线：完整路径与实例验证

沿贝塞尔曲线完整长度等距取点，实例化单位 Icosphere，以逐点稳定随机半径均匀缩放；独立 Curve to Mesh 生成丝线。验证脚本检查实际随机半径范围、XYZ 缩放一致、首尾附近覆盖及评估后的丝线网格。

本次半径范围为 0.0025–0.012，仅是现场值。保留下来的脚本包含上述断言，但本次整理没有对应最终球数的结果文件，因此不补造球数。操作中旧式修改器参数写法不适用，后续以 `modifier.properties.inputs` 接口处理。该经验支持版本发现与输出验证，不需要另收一份绑定工程名的构建脚本。

## 湖面：迁移有效不等于视觉满意

用户要求复用源集合的碰撞涟漪，将碰撞集合替换到目标湖面。复制源组及材质后，处理相对空间、缩放、距离遮罩属性和材质消费者；随后尝试增加采样、投射均匀效果层，并在用户明确允许后备份和 Remesh。

之后的多轮参数/材质调整试图减少规则的多层条纹。用户先反馈不自然，又反馈新版本“完全看不到”，要求恢复上一版。恢复脚本从本轮材质备份与参数快照恢复，保留已有 Remesh，并核对恢复值。

因此只沉淀空间/属性/采样检查和回退粒度；不把本次阈值、频率、发光、Remesh 尺寸或投射层方案称为自然水波的通用预设。记录中的“无节点警告”不能证明美术目标达成。某些迁移参数仍通过属性跨到材质，这只是当时方案，不是后续简化粒子必须照搬的面板设计。

## 空气粒子：减少兼容分支并验证形状

现场为 Blender 5.2.3 LTS / Cycles。原空气粒子组有 105 个节点，包含包围盒分布、贴片和点渲染分支；用户要求实际网格内部造型、真实点渲染常开、材质解耦、简化控制和逐参数说明，随后补充基础漂浮与显隐动画。

检查“风格化云”参考发现，它从表面分布并做摄像机投影贴片，不包含原先设想的体积转换。因此新组采用网格转体积再内部分布；原对象、网格、修改器及材质保留在隐藏备份中。

已保存的最终检查记录：38 个几何节点、10 个控制、4 个 Panel、全部控制有说明、无无效链接。目标源网格为 8 顶点的变形容器，最终密度 100 时得到 113 点。数量不是固定预算，也不能把该输入称为标准立方体。材质外层仅组节点和输出，组内为输入、Emission、输出，提供颜色与发光强度。

接口替换后第一次独立读取发现密度=0.5、最大半径=0 等旧值仍在，不是新版默认值；明确写回新控制后再次读取得到预期值。这是重新设计接口时要验证实例值的直接依据。

### 体积宽度的对比与边界约束局限

在单独生成的边长 2 标准立方体、分布密度 30 的对比中，Interior Band Width 为 0 / 0.05 / 0.2 / 3.46 时，分别产生 203 / 203 / 182 / 58 点。后两者还更明显地收缩有效分布范围。此测试推翻了“将对角线作为内部厚度即可均匀填满”的实现假设；最终使用 0。它不构成其他版本/模型必须同值的规则。

动画检查记录显示，代表两帧中目标的 42 点数目一致、42 点移动、26 个半径变化；整体显现=0 的最大半径为 0。最终提高目标默认密度后得到 113 点，但没有重复上述整套帧检查，不能把早期 42 点结果标成最终配置的完整动画验证。

猴头高密度输入产生实际点云并完成渲染；薄耳等细部仍较稀疏。极大漂浮幅度测试中，最终一轮得到 1046 点，另行 BVH 最近表面法线符号检查仍判出 8 点在外侧。该检查本身不是通用 inside 算法，模型开口/拓扑、采样法线及约束之间的具体原因未确定。因此“粒子中心始终在任意网格内部”的说法不成立，只能将距离限幅和删点作为减少外溢的方法，并要求代表模型复验。

显隐通过半径缩放实现，没有透明淡出、位置重生或自绘贴图。点云没有平面贴片的现成 UV，当前能力只到发光圆点；以后需要自绘任意轮廓时应重新判断表示方式。用户提出的贴图需求不能被这次简化结果视为已实现。
