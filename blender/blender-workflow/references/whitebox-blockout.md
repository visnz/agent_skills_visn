# 参考图白盒搭建：比例与视觉规律

用户要求白盒、Box 粗模、用基础体概括参考图、调整建筑与人物比例时读取。连接、社区资料及现场保留沿用上级技能；本流程关注尺度与空间判断，不扩展为精细建模。

## 先确定交付阶段

- 用户只要二维概括图时，先交付概括图；有参考图不等于已授权建 Blender 工程。用户要求直接搭建时，再制作可编辑白盒及摄像机。
- 将主体识别为盒体、楔形/三角棱柱、球体等大形，保留主要轮廓、遮挡与空间层次。屋顶可用楔形或收顶盒体，植被可用简单体块；不让细节掩盖比例问题。
- 区分参考图中可见的关系、用户明确的空间条件和从单图推测的尺寸。单张透视图不足以唯一确定进深，合理假设应可修改。
- 需要生成二维概括图时，检查当次真实可用的图像生成/编辑技能和工具。能读图、能渲染 Blender 与能调用生图是不同能力；不能用其中一种能力证明另一种存在。能力缺口与待验证方案见 [探索记录](2026-11-09-courtyard-blockout.md)。

## CG 静态帧的取舍：主相机画面优先

用户于 2026-11-10 明确的此类任务偏好：通常制作 CG 静态帧，最佳角度与好看的构成比空间处处真实更重要。以最终画面为交付，不默认要求场景从任意角度都成立。用于建筑测量、实景复原、多视角资产或漫游时，按本次要求恢复相应的真实空间约束，不能直接沿用单镜头的处理。

决策优先级为：**画面意图与构成 → 镜头内的可信度 → 空间真实性**。真实尺度用于建立人物与环境的可信关系；镜头后方进深、画外结构和背景间距可以服务构图。用户说“比例正确”时，结合交付语境判断，不能自动解释为全场景严格等比例；明确要求的尺寸仍保留，用户后续放宽的部分则更新约束。

先确定主相机里需保留的视觉关系：门框或前景框景占比、主体与人物大小、轮廓与遮挡、留白、视线引导及前中后景层次。把其他空间条件作为可调变量，不因现有房间尺寸锁死相机而接受横梁出画或主体被遮挡。

| 可调整的空间条件 | 验证重点 |
| --- | --- |
| 扩充镜头后方房间、移动画外墙体以容纳机位 | 主视角框景是否保留；画内阴影、反射、间接光是否受影响 |
| 独立移动、拉开、错位或局部缩放背景体块 | 主体占比、轮廓、重叠与远近尺度是否协调；不能只看俯视布局 |
| 调整机位、焦距、移轴及确有必要的主体站位 | 构图、透视与接触是否同时成立；保留用户最新站位意图并说明必要变动 |
| 简化或省略画外结构 | 是否仍在画内投影、反射或产生遮挡；画外不等于对成像无影响 |

焦距、机位与背景布置联合求解。增加焦距并后退可恢复前景框景，同时改变远近物体的相对占比；这不是单靠焦距自动获得的“透视压缩”。背景后移过多会抵消其放大效果，需看图与屏幕占比一起判断。镜头移轴能重新安排画幅，但不能消除地板对人物的真实遮挡；提高机位也会改变背景在门框中的高度，不能只解决脚部后就停止检查全图。

副视角用于排查会影响主视角的穿帮和接触，不作为所有方向都必须漂亮的验收要求。保留可回退版本，简报为构图做了哪些空间调整。单帧方案需要新增机位或动画时，重新检查此前隐藏的接缝与遮挡。

## 用尺度基准支撑镜头判断

先用人物、门洞或用户给定长度建立一个可信尺度锚点。明确场景单位、人物实际总高、主体宽/深/高及地面标高；不要把临时建模尺寸当成真实建筑尺寸。人物高度按本次角色或用户要求选取，1.7 米只是本案例的成人占位值。

同时检查两类比例：

| 世界空间 | 摄像机画面 |
| --- | --- |
| 建筑宽、深、墙身高、含屋顶总高 | 前中后景体块占画幅的比例 |
| 人与门、柱、台基的尺寸关系 | 透视缩短、近大远小、遮挡关系 |
| 柱网、开间、台阶和接触标高 | 主体轴线、左右视觉重量、可读轮廓 |

用户明确要求“近景房间与远处大殿一样大”且指实际尺寸时，以世界尺寸相等建立基线，不能用屏幕包围框相等冒充。若后续允许为静态帧扩充隐藏空间，则同进深不再是该部分的硬约束；保留仍然有效的可见宽度、开间和尺度关系。局部缩放或非真实布置要有具体画面收益，并说明取舍，不能将未说明的变形当作尺寸正确。

用户重新摆放人物后，重读当前对象、合并后的几何及世界包围盒。以总高和脚底标高校验，而非物体原点或名义缩放值。整体场景调整时区分人物站位与人物身高：站位可随场地等比变化，身高按尺度锚点独立控制；需要居中时保留两人的间距与前后关系，并说明整体平移。

## 让简化建筑仍有结构逻辑

- 先建立中轴、柱网与地坪，再放墙体、门洞、屋顶、台基。等宽开间来自同一套计算，不逐根凭画面手调柱子。
- 对包含端柱的总宽 W、n 个净开间和统一柱宽 c，可用净宽 `(W-(n+1)*c)/n`，柱距为净宽加 c；确认 W 的定义确实包含端柱。不同建筑采用不同模数时按实际结构处理，不强制所有间距一样。
- 对称优先检查相机、中轴、主体与柱网；侧殿或植被不必机械镜像。保持用户要求的对称程度以及参考中的合理差异。
- 台基顶、室内地坪、门槛、楼梯顶与院落地面需形成连贯标高。踏步高度和深度以使用尺度核对；高度差、级数和踏步高应一致。
- 用 Array 生成台阶时，核对对象缩放与偏移所处空间，并检查求值后的实际尺寸。长盒层叠可以形成实体台阶，但隐藏的延伸部分应被台基容纳，不能穿出室内可见面。
- 室内地板与台基顶不要完全共面，以免预览出现条纹；地面应覆盖建筑支承区域。轮廓简单不代表可以悬空或留下结构断接。

## 整体缩放与多轮修改

针对本次集合记录对象身份、父子关系、变换和关键尺寸，保留能回退的基线。修改前一次性检查目标范围和层级，避免边改边发现摄像机还有父子辅助对象。可按根对象变换或计算目标世界矩阵处理层级，但不能让父变换与子变换重复计入同一个倍率。

人物、摄像机、焦点辅助对象、实例和修改器的参数分别判断，不把所有数值盲目乘同一倍率。整体缩放后重新检查裁剪范围及焦点目标，尤其是启用景深时。

脚本中断后先比较当前状态与修改前快照，识别已完成、未完成和用户新编辑的部分。不要盲目重跑乘法缩放；有歧义的对象先重读，避免用旧快照覆盖新编辑。优先从已验证基线计算绝对目标值。单次现场脚本未参数化、未跨场景验证时，不直接包装为通用工具。

## 验收与收尾

在必要的 view layer 更新后读取世界尺寸；修改器相关结果读取求值几何。检查本次仍有效的尺度锚点、主体尺寸、开间、接触与明确的同尺寸约束；区分真实基准和为构图调整的部分，报告时区分墙身高与含台基/屋顶总高。

用实际主相机图检查框景、透视、主体位置、人物可见性和轮廓；必要时用屏幕占比及门框边缘位置与基线对照。台基/楼梯的接触或画内投影需要排查时，再补外侧视角。临时验证后恢复主相机和相关渲染设置。数值检查用于解释结果和排查穿帮，不能因为隐藏空间偏离现实而否决已符合目标的静态帧。Workbench 预览只能证明当前白盒成像，涉及画外结构对阴影、反射、间接光的影响时，在目标渲染引擎中另行确认。

交付保持可编辑基础体，简报实际尺寸、相对布局的改动、检查结果及保存状态。只在本次要求持久化时保存工程，不为白盒阶段增加无关细节、导出或发布。
