# 既有节点效果：诊断、迁移与参数简化

仅在用户要求修复当前节点效果、迁移效果到另一对象、简化已有系统或整理可调面板时读取。社区技术资料按 [community-routing.md](community-routing.md) 选择；资产入库仍用 [asset-library.md](asset-library.md)，带驱动资产同步用 [asset-sync.md](asset-sync.md)。这里补充个人协作方式和已遇到的实现陷阱。

## 从症状找到实际控制链

读取目标对象、修改器/材质实例、引用组和输出分支，追踪参数到实际输出的路径。记录接口默认值、实例值、外部连接和驱动 owner；参数名称相同不代表读取同一个实例。用户边工作边让 Agent 操作时，初次确认目标后保留对象/数据块身份，后续选择变化不应悄悄切换目标；修改前确认目标没有进入编辑模式或被用户改变了待改结构。

| 现象 | 优先核对 |
| --- | --- |
| 参数改变但输出不变 | 当前使用的材质/修改器、启用分支、是否被连接或驱动覆盖、值域是否已被 Clamp/阈值截断 |
| 可见度为 1 仍看不到效果 | 昼夜或模式分支、密度/大小/强度、渐变遮罩、主控实例；可见度只控制其中一环 |
| 换了网格，粒子仍是方块 | 分布输入来自实际网格、表面、体积还是包围盒；包围盒只提供范围，不保留内部形状 |
| 已复制节点，目标效果仍不同 | 材质与属性依赖、采样域、网格分布、修改器顺序，以及源/目标坐标空间与非均匀缩放 |

不要只因 driver `is_valid` 就断言参数正确。它可能仍解析到一个有效的 `inputs[index]`，却已指向其他 socket；路径与语义检查沿用资产同步参考。

插入 HSV 等处理节点时，先枚举目标输出的全部下游连接，再经新节点重连所有消费者；不要只改找到的第一条链接。保持中性默认值，例如 Blender HSV 节点 Hue=0.5、Saturation=1、Value=1，并核对未调节时的效果。

## 修改与回退的粒度

- 修改共享节点组或材质前，列出范围内使用者；需要独立效果时复制相关数据块。对象副本仍可能引用同一节点组/材质，不能只复制对象后继续原地改共享图。
- 改造完整系统时保留可还原的对象、网格、修改器输入、节点组与材质；单纯 fake user 保留一个组，不能恢复被改过的实例值。用户请求回到“上一版”时，以本轮调参前的快照恢复，不默认回到最初导入版本。
- 对重拓扑/Remesh 和视觉调参分别留状态：前者改变采样与几何，后者改变材质和数值。用户只回退视觉版本时，不顺带撤销已接受的网格处理。
- 每轮只动有解释依据的一小组参数，使用同一视角、帧和显示模式比较。效果变弱时先确认对比条件与有效遮罩，不无依据地同时提高密度、亮度和分辨率。

## 接口与面板：保留功能映射

给已有组增加输入时，优先追加到原有输入之后。使用 `move_to_parent` 整理折叠 Panel 后，比较原 socket identifier、类型、输入顺序，以及实例、外部链接和驱动路径；整理面板也可能影响以数值索引定位的控制链。

若按用户要求重建并简化接口，新旧 socket identifier 可能碰巧重用。替换修改器组后不要假定新默认值已经生效：按名称、类型和语义明确迁移需要保留的实例值，其余赋予新默认值。接口更新、依赖图更新后，在下一次独立读取中复核。

本次 Blender 5.2.3 LTS 现场的修改器输入通过以下接口读写，旧式 `modifier[socket.identifier]` 曾报不支持 ID properties。其他版本先发现运行时 API，不机械套用版本号：

```python
socket = next(s for s in group.interface.items_tree
              if s.item_type == 'SOCKET' and s.in_out == 'INPUT'
              and s.name == wanted_name)
prop = getattr(modifier.properties.inputs, socket.identifier, None)
if prop is not None:
    prop.value = wanted_value
else:
    # 仅在已检查该运行时支持旧接口后使用。
    modifier[socket.identifier] = wanted_value
```

全局数值控制可在 API 支持时设置 `force_non_field`，减少不需要的属性输入。随机值、Mix 等多类型节点用实际启用的 socket 和 identifier 连接，避免同名隐藏输入。接口和 node socket 不是同一对象；使用前检查实际类型。

用户要求易调面板时，按视觉用途分 Panel，低频精度参数默认折叠。通过接口 socket 的 `description` 写悬停说明，至少解释视觉含义、数值增大/减小的方向、单位和 0 的特殊含义。非单调参数如随机种子应明确“更换排列，不代表更多/更少”；色相解释中性值与循环，不编造单调变化。

## 迁移碰撞/距离效果

先复用源的有效计算部分，核对 Collection Info 的空间、是否需 Realize Instances、属性名称/类型/域及材质消费者。排除目标对象混入自己的碰撞集合。

几何节点在 POINT 域写距离遮罩时，稀疏、狭长或分布不均的顶点可能无法描述窄碰撞范围。先观察有效遮罩与评估后采样分布，再选择：

- 原网格采样已足够：保留网格，调节效果参数。
- 只需要水面效果层：可用均匀网格 Raycast 贴合原表面，删除未命中和不需要的朝向；处理层间偏移、透明/反射和重叠闪烁。这是条件性方案，不保证更自然。
- 用户授权改变几何：备份后使用适当 Remesh，核对轮廓、厚度、法线、开口与评估后面数。几何节点内部仅增加细分也可能使成本明显升高。

距离计算双方须处于一致空间；非均匀缩放下的局部欧氏距离不等于世界距离。迁移时显式核对变换，别把某次现场 scale 写成永久常量。具体验证可比较已知碰撞位置、范围和遮罩。

波纹自然感同时受采样、距离场、材质频率/阈值、粗糙度、发光、镜头与光照影响。已连续改变多个环节时先恢复可比较基线；遮罩非零和节点无警告不能代替用户认可的视觉结果。

## 按需求简化粒子系统

先辨认旧系统承担的功能：分布、大小、运动、生命周期、渲染表示，以及材质外观。用户只要基础粒子时，删除无须保留的兼容分支并保留完整备份；节点数量下降只是复杂度指标，仍要检查行为。

几何节点负责空间造型、半径、运动与显隐时间；颜色、着色与贴图放在材质。确实需要的跨树数据，例如生命淡出或碰撞遮罩，可以保留最小且有语义的属性契约，不为解耦强行删除功能。不要把全部外观参数重新放回几何面板。

真实点云与摄像机朝向贴片是两种表示。用户要求真实点渲染且当前版本/引擎已验证支持时，可移除贴片兼容开关并固定输出点云；不能据此推断所有引擎与导出格式均支持。自绘图案需要可定义的贴图坐标；真实点没有平面贴片的现成 UV，任意星形/花瓣轮廓可能需要贴片或额外映射。两项需求冲突时说明实现取舍，不把未接入贴图的发光圆点描述成已支持自绘图案。

### 体积造型与动画的实测注意点

- 需要实体内部粒子时可采用 Mesh to Volume → Distribute Points in Volume。检查参考对象是否真的体积化；本次名为“风格化云”的图实际从表面分布再投影贴片，不能凭集合名称照搬。
- 用密度控制时，总数取决于体积、体积密度场和随机种子；不能把每立方单位密度解释成固定总数。细薄部分还受体素分辨率影响。优先以合理精度验证轮廓，再提高密度；更高精度的内存/计算增长可能很快。
- 本次 Mesh to Volume 的 Interior Band Width 实测改变有效密度：将容器对角线当成“填满内部厚度”会让相同分布密度下的点数明显下降。该现场较小宽度/0 有效改善密度；后续版本和模型应比较输出，不能写成所有版本必须为 0。
- 稳定随机 ID/种子与 Scene Time 驱动的平滑噪声可完成无模拟漂浮。按到表面的距离限制偏移有助于减少外溢，但最近法线符号测试不是真正的通用 inside 判定，开口、自交和非流形网格尤其需要验证。粒子中心在内部也不代表整个半径都在内部。
- 若只需循环长大/缩小，可由时间相位、逐点随机相位和平滑过渡乘到半径，减少材质耦合。明确这不是透明淡出、位置重生或物理生命周期；时长 0 关闭循环、整体显现 0 隐藏等行为须实际测试。

## 对结果做有针对性的验证

- 接口：检查实际实例值、全部相关链接、原驱动的正确 socket，以及面板/说明；在隔离副本中改变代表参数，确认输出发生相应变化。
- 分布：用已有评估接口，或仅在验证副本中接 Points to Vertices，检查点数、坐标、半径和轮廓；包围盒范围只能排除越界，不能证明点位于凹形内部。与源网格比较时读取真实顶点/面，不能因有 8 个点就把变形容器当成标准立方体。
- 动画：以一致 FPS 检查代表帧的坐标/半径变化，以及静止、循环关闭、完全隐藏等明确边界条件。只有数目一致不能证明轨迹或完整循环正确。
- 曲线串珠：沿完整曲线等距采样、逐点随机均匀缩放，可保留球体实例；检查首尾附近覆盖、实际半径范围和三个轴的缩放一致性。遍历 `depsgraph.object_instances` 时立即复制坐标/矩阵/尺度，RNA 实例引用跨迭代保存后可能失效。
- 视觉：必要时使用隔离场景和代表输入渲染，保留主工程视图/选择/渲染设置。清理自己创建的验证数据；测试图不自动进入用户场景或资产库。按保存授权交付，不将截图或成功调用当成持久化证明。
