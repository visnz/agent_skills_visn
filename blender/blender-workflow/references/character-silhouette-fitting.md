# 已有绑定角色按参考图校准素体、局部体态与二次元五官分层形态键

用于用户提供正/侧/背/多视角角色参考图（含 AI 生成设定板、局部体态照片或其他 `.blend` 素体），要求在**保留原有拓扑、UV、表情形态键与骨骼控制器**的前提下，分轮修改已有角色素体比例、局部体态（盆骨/腿踝/纤骨手）与二次元脸部五官（脸型头骨、六边形眼眶、分簇睫毛、眉鼻唇、可调瞳距及眼睛着色器），并同步骨骼/控制器的任务。

开始修改前按主入口先装载 `blender-core`、`blender-sculpting`、`blender-character-rigging`、`blender-facial-shapekeys`；涉及眼睛贴图与着色器核验时一并装载 `blender-pbr-materials` 与 `blender-rendering`。

> **高效参考图输入与协作建议**：
> - **头脸与发型体块**：包含**正面、正侧（带头发半透明露出耳位与下颌角更佳）、背面、45° 侧、俯视 45°、仰视 45°** 的统一设定板效率最高，能同时锁定正面 V 脸宽度、45° 颧颊转折面与侧面颏下斜度。
> - **毫米级局部造型（如二次元睫毛分簇尖刺、髌骨内勾、手指骨感）**：全景设定图分辨率有限时，切勿把低清图里的概括粗黑线当成“抹平原有精细结构”的指令；配合一张局部特写或在 Blender 视口截图上直接勾红线/箭头即可一次对齐。

## 为什么常规 AI 脚本改模型极易翻车（五大核心准则）

常规大模型脚本在改绑定角色时往往反复折磨用户，根源在于五个典型失误。执行任何角色修型前必须逐条规避：

1. **盲按总高百分比缩放 vs 锁定场景相机矩阵与解剖硬点**：参考图蓬松发顶/马尾常高于裸颅骨 `3%~8%`，按总高归一化会导致全身拉长、胯腿手脚被按错误比例缩窄。
2. **直接改 `Basis` vs 姿态评估采样 + 逆蒙皮矩阵（Inverse LBS）回写**：A-pose 建模的角色摆成 T-pose 对照参考图时，世界空间位移必须经变形骨姿态旋转矩阵求逆后再写回形态键。
3. **全自动描像素边缘 vs 剥离二维遮挡 + 三维人体解剖先验**：直接拟合非白像素会把垂落发丝变成“尖耸斜方肌”、把侧视平举手掌/马尾变成“喉部前凸与后背驼峰”。
4. **单次破坏性覆盖 vs 多轮分层形态键 + 严格保护用户滑块值**：用户常在已生成的形态键上手动微调权重（如 `0.4 / 0.5 / 0.8`），甚至在同一形态键的不同档位挑出各子部件最佳状态（如“`0.3` 眼型 + `0.2` 上眼睑 + `1.0` 眉毛”）。必须快照并保留用户所有既有滑块值，支持按连通子岛做多档位加权合成。
5. **无视细分曲面与多层透明面片关系 vs 正向 BVH 防穿模 + 动画层零写入**：二次元眼睛含十余层独立面片，盲目塞进形态键会导致拉滑块时高光横跳、双眼皮穿进鼻根细分皮肤，甚至射线穿过眼眶开孔误中后脑壳。

## 第一部分：身体三视图校准、跨参考融合与骨骼同步（`01..08` + `B01..B03`）

### 1. 锁定统一世界坐标，严禁凭裸头顶高度盲猜缩放

- **优先复用场景参考图对象**：若工程中已有对齐角色的参考图 `Empty`（`empty_display_type == 'IMAGE'`），直接读取其 `matrix_world`、`empty_display_size`、`empty_image_offset` 与图像像素尺寸，建立像素 $(px, py) \leftrightarrow (X, Y, Z)$ 精确变换，让正交验证相机与参考图共享完全一致的 `ortho_scale` 与中心：
  $$X = x_0 + \left(\frac{px}{W} + \text{off}_x\right) S_x,\qquad Z = z_0 + \left(\frac{H - py}{H} + \text{off}_y\right) S_z$$
- **无场景 Empty 时的标定基准**：用脚底接地高度与**无遮挡解剖硬标志点**（耻骨联合下缘、肚脐、胸骨上切迹/锁骨窝、内踝）标定比例，绝不用参考图的头发最高点对齐裸模颅顶。

### 2. 区分静息态（A-pose）与当前姿态（T-pose），用逆蒙皮矩阵回写形态键

1. **姿态网格采样**：临时将 `Outline`（反向壳描边）与 `Subdivision` 修改器的 `show_viewport` 置 `False`，通过 `target.evaluated_get(deps).to_mesh()` 读取当前姿态下的真实世界顶点坐标 $p^{\text{pose}}_v$，在此空间与参考图轮廓包络做切片比对。
2. **逆线性混合蒙皮（Inverse LBS）回写**：对每个顶点汇总所有变形骨（如 `bn_*`）的姿态旋转矩阵加权和：
   $$M_v = \sum_i \frac{w_{vi}}{\sum_j w_{vj}} \bigl(P_i B_i^{-1}\bigr)_{3\times 3},\qquad \Delta p^{\text{basis}}_v = M_v^{-1}\,\Delta p^{\text{world}}_v$$
   将世界空间位移左乘 $M_v^{-1}$ 转回 `Basis` 局部空间后写入形态键，确保在开启 Armature 姿态下顶点精确落到目标位置。
3. **A→T 抬臂“塌肩”修复**：A-pose 素体抬臂 `50°+` 成水平 T-pose 时，LBS 会令三角肌上缘与锁骨外端下陷。需先在关节层适度抬高锁骨/肩峰枢轴，再在姿态评估网格上用 `肩臂轮廓` 形态键补偿肩峰—斜方肌上缘高度。

### 3. 剥离二维遮挡，并以人体解剖曲线约束三视图偏差

- **正视颈肩角散发遮挡**：垂落发丝常填满耳下至锁骨内侧（$|X|$ 较小区域），须过滤深色发丝像素并用平滑斜方肌解析曲线过渡，避免拟合成耸起的“尖角斜方肌”。
- **侧视水平手臂/拇指与马尾遮挡**：T-pose 侧视图中，平举的手掌与下垂拇指会挡住颏下与前颈喉线，后侧三角肌与马尾会挡住 C7 至上背。该区段禁止直接追随像素外缘。
- **颈背—肩胛—腰曲人体 S 曲线与前后胸背解耦**：
  - 侧视后背须遵循连续二阶光滑解剖曲线：**枕骨外凸 → 颈椎前凸柔和内收（颈窝）→ C7 颈胸过渡 → 肩胛骨/胸廓圆润外凸 → 腰椎前凸内收**；前侧遵循 **下巴 → 颏下斜坡 → 垂直喉线 → 胸骨上切迹转入上胸自然斜坡**。
  - **前后胸背解耦**：女性角色前胸调整幅度大，计算上背与肩胛厚度时必须以脊柱/胸腔后侧基准单独向 `+Y` 映射后背顶点，**严禁使用 `(y_front + y_back) / 2` 全截面中点**，否则前胸隆起会反向拉瘪后背造成肩胛凹陷。
- **跨视图局部高度漂移校验**：三视图之间常有轻微低头或 `1%~2%` 高度漂移。以主正视图锁定 `X/Z` 高度，侧视图先按局部硬特征（下巴—鼻尖—眉心）对齐高度后再提取前后 `Y` 纵深。

### 4. 外环二阶曲面投影法（抹除密集乳头 / 厚重写实嘴唇的通用利器）

当需要把高密度局部凸起（如裸模乳头/乳晕，或欧美/写实风外翻厚唇）改为光滑二次元胸坡或瓷滑微笑唇面时，单纯做拉普拉斯邻域平滑只会把密集面片缩成残留尖刺或法令纹折痕：

1. **外环采样拟合基底曲面**：避开中心凸起圆盘，采集外围干净过渡环带（如乳房外环或口周 $r \in [0.105, 0.195]$ 环带）拟合二阶最小二乘曲面：
   $$Y_{\text{base}}(x, z) = c_0 + c_1 x + c_2 z + c_3 x^2 + c_4 x z + c_5 z^2$$
   （中轴对称区如嘴部采用偶对称基 $1, z, x^2, z^2, x^2 z$，从数学上杜绝中线折痕）。
2. **切向均匀松弛 + 法向投影**：先对圆盘内过密的顶点在 $(X, Z)$ 切平面做迭代松弛消除面片挤压，再按平滑径向权重投影到 $Y_{\text{base}}(x, z)$（嘴部可叠加毫米级二次元上唇微阶与嘴角上扬曲线），最后在交界环做 3–4 轮轻量切向平滑，即可在素模与三渲二下同时获得零折痕的瓷滑过渡。

### 5. 模块化形态键拆分、交界防断层与跨参考分层叠加

- **保留用户滑块值与幂等重建**：首次修改前备份原始 `Basis` 与骨骼快照；后续每轮重建**只移除当前轮次前缀的形态键**（例如重算 `C0*` 时绝不动 `01..08`、`B01..B03` 与原有 `eye_blink_*`/`mouth_*`），脚本末尾强制断言 `preserved_values == after_values`。每完成一大轮用 `bpy.ops.wm.save_as_mainfile(filepath=..., copy=True)` 留存阶段暂存文件，保持用户当前打开的主文件不切换。
- **防止相邻分区交界断层（如“悬空臀”）**：相邻形态键（如 `腰臀腹` 与 `腿部`）若在臀下折痕处同时衰减为 `0`，交界带会退回原模型旧位置，形成臀部后翘而大腿内缩的生硬凹槽。跨区连续曲线须采用**单位分解权重** $w(z) + (1 - w(z)) = 1$，或在前序形态键评估网格上补充独立过渡键（如 `08_臀部过渡柔化`）做切向桥接。
- **跨参考局部造型融合（`B01..B03` 层）**：
  - **盆骨股骨与膝踝缩脚**：大腿环线较稀区域提取内外轮廓时，须分别过滤真内壁与真外壁顶点并平滑插值，避免空切片抓到正面顶点在腿面形成竖向凹痕；髌骨做内侧回勾、脚踝收窄曲线微抬，若后续需穿鞋可围绕踝关节枢轴整体微缩足部并锁住脚底接地 `Z` 高度。
  - **跨 `.blend` 素体手部参考与纤骨化雕刻**：读取外部参考 `.blend` 必须通过独立后台进程 `--background --factory-startup` 只读采样，绝不污染当前会话。手部去赘肉与纤骨化时：① 加深指缝根部去“鸭蹼”；② 让第二、三指节（PIP/DIP）宽度靠近并微雕指节骨点与手背肌腱面；③ 指节横向收窄从掌指关节根部后平滑渐入（$s \in [0.05, 0.52]$），保护小指尺侧外缘与独立指甲片子岛，防止小指根缩颈或甲片翘曲。

### 6. 关节位移的完整绑定层同步

复合绑定（Rigify 或带 IK/FK/Tweak 约束链的骨架）中，变形骨 `bn_*` 受控制层约束驱动；只改 `bn_*` 回到姿态模式会被立刻扯回原位：

1. 在 `Edit Mode` 按同一关节位移映射同步更新 `bn_*`、`ORG-*`、`MCH-*` 与 `ctrl-*`（`use_connect = True` 的子骨仅由父骨 `tail` 带动），按旋转差调用 `eb.align_roll(...)` 保持骨滚角。
2. 回到 `Object/Pose Mode` 后遍历全部 `STRETCH_TO` 约束设置 `rest_length = 0.0` 重置静息长度，并核对当前 IK 控制器与极向量使视口姿态零跳变。

## 第二部分：二次元脸部五官、多子岛眼睫毛、瞳距滑块与着色器（`C01..C03`）

二次元头模（如 `AnimeFemaleBaseMeshAgeKit` 等）通常把整颗头的皮肤与 **30～40+ 个独立连通子岛**合并在同一 `Mesh` 内。动手前必须先用 `bmesh` 连通分量 + 材质槽 + UV 框做精确测绘。

### 1. 头部连通子岛与眼眶边界环精确分类

先分离最大连通分量作为皮肤主岛 `skin_mask`，在皮肤主岛上提取 $Z$ 位于面部高度的开放边界边（`e.is_boundary`）顶点并按邻接关系顺时针排序（内眼角 → 上睑弧 → 外眼角 → 外下斜睑 → 平直下睑 → 内下睑），得到精确的眼眶边缘环 `eye_rim`（如单侧 27 点）。其余子岛按材质与 UV 归类：

- **口腔子岛**：上牙、下牙、舌头（随嘴部高度/前后位移同步刚体平移，防止嘴唇上提后露牙穿模）。
- **眼外造型子岛（可入五官形态键）**：眉毛带、悬浮上眼睑（双眼皮）折线带、主上睫毛带、内侧上睫毛分簇刺、外侧上睫毛分簇刺、外下睑细小下睫毛点缀。
- **眼内动画子岛（五官形态键严禁改形！）**：白眼仁壳（Sclera）、主虹膜圆盘（Main Iris）、半透明内层虹膜光晕（Inner Iris）、瞳孔片（Pupil）、半透明角膜上睑投影罩（Cornea Shadow）、多层高光面片（Highlights）。

### 2. 脸型头骨（`C01`）与鼻唇微笑（`C02` 下半脸）要点

- **多视角脸型协同（`C01`）**：正面收顺 V 型椭圆下颌线与收贴外招耳廓；45° 视角微收口角旁颊脂垫并保留高颧骨微高光；正侧校准颏下斜坡（下巴底至喉部上收斜率）与微收颅顶裸高。
- **鼻根与内眼窝解剖协调（防穿模关键）**：二次元侧面鼻根（山根）较浅，向 `-Y` 前填山根时横向范围必须严格收窄在中线鼻梁（$|X| < 0.08$），并在**内眼角上方眼窝区（$|X| \in [0.085, 0.22]$）保留 `5~7 mm` 的解剖学眼窝微凹**。若把整个眉心连同内眼窝一起往前推，内侧双眼皮与内睫毛会立刻陷进鼓出的脸蛋皮肤里。
- **人中—鼻尖—微笑唇单调联动**：上提嘴部位置时，人中与鼻尖底部须用连续平滑权重同步微抬，防止上唇单独上移挤压人中产生横沟。

### 3. 眼眶轮廓、分簇睫毛与“眼内动画层零写入”铁律（`C02` 眼部）

1. **眼内高光与半透明层零写入（铁律）**：
   - 在五官造型形态键（`C02`）中，**所有眼内子岛（高光面片、半透明角膜阴影、内层虹膜、瞳孔、主虹膜、白眼仁）的变形量应严格保持 `delta = (0, 0, 0)`**，改为微调眼眶 `eye_rim` 与睫毛的高度和开合轮廓去框选原眼球。
   - **原因**：眼内多层虹膜与瞳孔在贴图上常有叠印中心，且高光面片在 `Basis` 中往往左右非严格对称；一旦写进静态五官形态键，不仅拉滑块时高光会在瞳孔上横跳、多层瞳孔错位重影，还会干扰后续 `bn_eye` 骨骼与表情动画控制。
2. **六边形二次元眼眶比例**：收窄内外侧过多眼白，塑形为「略低内眼角 → 圆弧上睑（自然轻遮虹膜上缘约 `10%` 避免瞪眼感）→ 平直中段下睑 → 约 `45°~52°` 陡斜外下睑（切掉外下侧松垂眼白袋）→ 微抬外眼角」。
3. **睫毛外轮廓的美术平衡（保留灵动分簇 + 收短横飞尾翼）**：
   - **反例警示**：不要因为角色三视图分辨率低、把睫毛画成一条黑弧线，就把 3D 模型原有的内外侧睫毛分簇尖刺（`lash barbs`）全部压平藏进主睫毛带，否则 3D 视口会显得光秃呆板。
   - **正确做法**：完整保留内外侧各两簇灵动的睫毛分刺与外眼角下包折角，**只针对主睫毛最外侧过度横飞向太阳穴的长尾尖做向内收短**，同时将上眼睑（双眼皮线）内侧过长的隐藏分叉修短至内眼角起笔处。
4. **多档位视觉择优一键合成**：
   当用户在视口测试形态键并反馈“某档位（如 `0.3`）眼型大小与瞳距好、另一档位（如 `0.2`）上眼睑好、`1.0` 眉毛鼻唇好”时，直接导出评估网格在对应档位的顶点状态，按连通子岛与平滑区域权重精确合成到新的满值 `1.0` 形态键中，无需推倒重猜。

### 4. 细分皮肤正向 BVH 射线防穿模与“穿透眼孔误中后脑壳”致命陷阱

视口开启 `Subdivision`（细分曲面）后，凹凸曲率变化会使未细分状态下看似贴合的双眼皮与内睫毛陷入细分皮肤。必须执行细分后正向 BVH 间隙校验：

1. 将 `Outline` 置 `False`、`Subdivision` 置 `True` 获取评估网格，**排除 `eye` 材质面片、仅提取头部皮肤面片**构建 `mathutils.bvhtree.BVHTree`。
2. 对眉毛、双眼皮、上下睫毛的每个顶点 $(x, y, z)$，从相机前方 $(x, -2.0, z)$ 沿视线方向 $(0, +1, 0)$ 投射射线获取细分皮肤表面深度 $y_{\text{skin}}$，强制钳制 $y \le y_{\text{skin}} - 0.0042$（保持 `4.2~4.5 mm` 正向安全间隙），并沿边做 1–2 轮保间隙平滑，确保正/侧/45° 既贴合眼窝又零穿模。
3. **致命陷阱——过滤穿透眼眶开孔命中后脑壳的射线**：
   头部网格是中空闭合壳体，唯独左右眼眶是真开孔！当射线恰好穿过眼眶开孔内部或边缘 `1~2 mm` 时，会漏过前脸皮肤、直接穿过颅腔命中**后脑勺内壁**（例如前脸皮肤在 $Y \approx -0.50$，而后脑壳命中点在 $Y \approx +0.39$）！
   **必须加上前脸深度过滤**：
   ```python
   if loc is None or loc.y > -0.25:  # 过滤穿过眼孔打中后脑勺内壁的伪命中点！
       return None
   ```
   漏掉这行判断会把靠近眼眶边缘的顶点一把向后拉穿整颗头颅（产生 `0.8m+` 巨额位移与破面）。

### 5. 独立功能形态键：瞳距与鼻梁联动调整（`C03` 三段保形映射）

二次元角色加上刘海和侧发后，面部留白收窄，裸头合适的瞳距往往会显得中间太开。应在不绑定特定发型的情况下，单独提供 `瞳距与鼻梁调整` 形态键（默认 `0.0`，建议滑块范围 `-0.30..1.00`）：

- **三段式水平保形微分同胚映射**（设满值单侧最大内收量为 $D_{\text{ipd}}$，如 `24 mm`）：
  1. **鼻梁与山根区**（$0 \le |X| < x_{\text{inner}}$）：按 $|X| / x_{\text{inner}} \cdot D_{\text{ipd}}$ 做正比例水平压缩，使山根与鼻梁侧壁随内眼角同步自然收窄，中线锁死 `dx = 0`，绝不挤压内眼角；
  2. **眼眶与整套眼部组件区**（$x_{\text{inner}} \le |X| \le x_{\text{outer}}$）：对眼眶皮肤、上下睫毛、双眼皮以及**整套眼内子岛（眼白/虹膜/瞳孔/角膜/高光）施加完全相同的刚体水平平移** $-\operatorname{sign}(X)\,D_{\text{ipd}}$，并叠加头部水平曲率深度补偿 $\Delta Y = Y_{\text{head}}(|X|-D_{\text{ipd}}, Z) - Y_{\text{head}}(|X|, Z)$。这样无论把瞳距拉到任何档位，眼睛自身宽窄比例与眼内高光相对位置均 **100% 零变形**，且在满值 `1.0` 处同样做细分皮肤 BVH 防穿模校验；
  3. **太阳穴外侧过渡区**（$x_{\text{outer}} < |X| \le x_{\text{temple}}$）：平滑 `smoothstep` 衰减回 `0`，保持头颅外轮廓与耳朵完全不动。

### 6. 多层透明眼睛着色器、Blender 5.x 节点连线陷阱与贴图无损重绘

- **五官核验必须使用 `BLENDER_EEVEE`**：二次元眼睛最外层通常有一片 `Transparent BSDF` + `Emission` 混合的角膜阴影罩（`#0`），在 `BLENDER_WORKBENCH` 的 `TEXTURE` 模式下会被渲染成不透明灰白片挡住半只眼睛，必须用 `BLENDER_EEVEE` 渲染核验。
- **紧凑透明 UV 图集重绘策略**：一张 `2048×2048` 眼睛贴图常紧凑排布 19 个带柔和 Alpha 边缘的 UV 岛。直接用 AI 生图整张重绘极易产生数像素 UV 偏移或白边漏色；优先基于原图精确 Alpha 蒙版对主虹膜区与红棕睫毛区做赛璐璐分层重绘（**严格保持高光与半透明层的原始像素及 Alpha 100% 不变**），同时可将原始贴图单独提取出来附上局部虹膜生图提示词供多角色扩展备用。
- **无损接入材质与双视口激活**：在 `eye` 材质中保留原 `Image Texture` 节点不删，新增自定义贴图节点 + `0/1` 切换滑块 + `Hue/Saturation/Value` 微调节点，并将新贴图节点设为 `node_tree.nodes.active = tex_new`——这样用户在 **Solid（纹理颜色）** 与 **Material Preview / EEVEE** 两种视口模式下都能立即看到新瞳色。
- **Blender 4.x / 5.x `ShaderNodeMix` 同名插槽陷阱**：当 `mix_node.data_type = 'RGBA'` 时，节点内部同时存在同名但不同数据类型的多个 `A`、`B`、`Result` 插槽（隐藏的 `VALUE` 槽排在前面，真实的 `RGBA` 颜色槽排在后面）！直接写 `mix_node.inputs["A"]` 会连到隐藏的浮点槽导致输出变灰，必须按名称 + 类型精确查找：
  ```python
  sock_a = next(s for s in mix_node.inputs if s.name == "A" and s.type == "RGBA")
  ```

### 7. 修改器与脚本执行安全护栏

- **禁止在开启反向壳 `Outline`（`SOLIDIFY`）时跑 BVH 自交 QA**：Blender 5.3 下对负厚度反向壳描边网格运行全网格 `BVH` 重叠检查易触发宿主崩溃断开（`WinError 10054`）；评估与几何检查前务必先关 `Outline` 的 `show_viewport` / `show_render`，完成后恢复。
- **对称搜索容差区分皮肤与悬浮高光**：悬浮高光面片在 `Basis` 中常有数毫米不对称，镜像映射若死卡 `dist2 < 1e-6` 会导致未配对顶点把自身当作镜像伙伴产生跨脸错位；皮肤/睫毛对称匹配宜用合理容差（如 `dist2 < 1e-4`），非对称高光岛单独按连通岛中心 `sign(mean_X)` 分左右处理。
- **Windows PowerShell 脚本调用**：禁止在 PowerShell 中用 `python -c "...\"..."` 传复杂引号，统一写成独立 UTF-8 `.py` 文件或使用单引号 Here-String `@' ... '@ | python -`。
