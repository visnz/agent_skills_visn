# 可热重载插件中的临时 UI 状态

只在开发需要临时改动用户设置、稍后由按钮恢复的开关时读取，例如临时切换变换坐标系、枢轴点和 3D Cursor。不把此流程套用于普通的一次性 operator。

## 设计与验证

- 明确快照必须存活多久：仅单次操作、跨界面模式切换，还是跨代码热重载。若需要跨模块重新导入，普通模块全局变量不足以承担恢复记录；选择与目标寿命匹配的存储，例如 Blender 会话中的 WindowManager 自定义属性，并确认它在该插件实际重载路径中仍可读。状态键应绑定所操作的场景或上下文，不要只靠当前选择。
- 开启前先拍下要恢复的全部原值。开启失败时回滚；关闭时先恢复，成功后清掉快照。插件注销、文件切换和重复点击也要定义状态处理。若快照已丢，不能从当前模式推断原值；向用户明确显示缺少恢复记录。
- 按钮的高亮、按下状态和文字应来自同一份实际快照。Blender 的图标、`UILayout.operator(depress=...)` 和 `row.alert` 等 UI 能力按目标版本核对。后台测试可验证属性和状态迁移，前台点击与绘制仍需单独核对。
- 按实际功能与风险安排隔离测试，例如开启→关闭、开启→代码热重载→关闭、开启→禁用、目标缺失；需要时补重复点击、文件切换、多场景/窗口。此处是待选择的验证清单，不表示历史已全部通过。对比原值与恢复值；单独观察 UI 显示，不以 operator 返回 `FINISHED` 代替恢复验证。

## 经验来源与边界

2026-11-07 的 PondBekkan 摄像机视角开关在 Blender 5.2.3 中出现过：用户现场仍是 View/3D Cursor，而模块级恢复字典为空。该观察证明当时没有可用快照，不能确定原设置；模块热重载是与现象一致的失效路径。改把快照按 `scene.session_uid` 存于 WindowManager 后，隔离测试确认模块 `importlib.reload` 后关闭可恢复 LOCAL/ACTIVE_ELEMENT/Cursor 位置；测试还核对了 UI 参数存在。此结果不代表用户前台所有重载顺序都已验证，别把具体存储位置或键名规定为所有插件的唯一实现。

## 历史验证状态与接续条件

| 项目 | 当前记录支持的范围 |
| --- | --- |
| 用户现场仍处于临时设置，但恢复字典为空 | 已观察；原设置不可确认，不能仅凭此确定快照丢失的唯一原因 |
| WindowManager 快照在模块 importlib.reload 后用于关闭恢复 | 历史隔离记录确认该路径恢复 LOCAL/ACTIVE_ELEMENT/Cursor；不是任意插件卸载/重装或文件切换保证 |
| UI 参数存在 | 记录已检查；不等于前台按钮绘制、高亮与点击交互通过 |
| 普通开启/关闭、禁用、重复点击、目标缺失、文件切换、多场景/窗口 | 当前笔记未逐项给出实测结果，按任务需要补验，不能沿用为“全部通过” |

接续类似问题前先读本节，明确当前需要的状态寿命和实际重载入口。新试验分别记录快照仍可读、值恢复正确与前台显示正确，不将其中一项替代其他项。若快照缺失，停止猜测恢复，不为重建记录擅自改用户设置。这里保留旧现象与局部成功证据，后续可按新的重载顺序或上下文继续探索；本次仅维护文档，未重新操作插件。
