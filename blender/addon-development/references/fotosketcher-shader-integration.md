# Shader 图片节点接入 FotoSketcher：方法与 2026-11-15 现场

适用：维护 Blender 5.2+ 插件里“选中图片节点 → 外部图像处理 → 导入结果并接管节点连线”的功能。以下编号、参数和程序行为来自 pond_bekkan 使用的经典版 FotoSketcher 3.97.1.1 及本次测试；换版本时重新核对。

## 可复用的实现与核对方法

- **限定目标**：从当前 Shader 编辑层收集所选 Image Texture 节点；弹出参数窗口时锁定节点名单。多图按顺序处理，失败记入汇总并继续。不要把“当前所选图片”扩大为全工程材质。
- **效果编号要实图比对**：GUI 菜单序号、.fsk 的效果字段和经典版 -silent 的效果 ID 不可直接等同。用同一原图、尺寸、五参数分别生成 GUI 完成图和 CLI 小样，按笔触/色调核对，并保留用户确认与仍待确认的边界。随机算法不要求逐像素相同；未经受控对照，不把亮度差归因于某个开关。CLI 的背景擦除选项是否与 GUI 一致仍待验证。
- **保留原图且可回退**：新图片以不覆盖源文件的名字输出，原 Image 数据块和原节点保留在旁；新节点复制采样设置、从原 Vector 输入接入同一来源，并接管原节点所有下游输出。创建或接线失败时恢复旧连线；结果文件仍应可定位。新节点自动选中，方便连续处理。
- **做 1K 副本时**：按钮单独执行，最长边 1024、等比缩放，已不超过 1024 的跳过；相同 Image 被多节点使用时只写一次副本，仍按每个原节点建新节点。对文件、打包或生成图片，先 image.copy()，在副本上 scale()，设置 file_format/filepath_raw 后 save()，最后移除临时 Image；临时输入导出同理。save_render() 会套用场景色彩管理，不能默认用于原色贴图副本。本次 5.3 隔离测试与原图缩放参考的平均 RGB 通道差：save_render() 约 14–16，save() 约 0.5；具体数值只代表当次图片。
- **异步反馈与备注**：外部程序可能把任务交给已有 GUI 进程，所以仅凭启动进程退出不可判断失败；等待结果文件大小和修改时间稳定，设超时并显示批次进度/失败。备注里的“生成耗时”从处理启动到结果文件稳定，不是完成时间点，也不含 Blender 导入。5.3 可用 Comment 节点存耗时、尺寸、实际参数和基准参数；5.2 用图片节点标签及文件名保留关键信息。由备注重试时读基准参数，避免再乘一次尺寸倍率。Windows 完成音可异步调用 winsound.PlaySound 系统提示音，但听觉效果需在用户现场验证。
- **验证层次**：单独核对 CLI 对 GUI 的笔触、隔离 Blender 中的原文件与 Image 不变、Vector 和所有下游连线转移、重复图片与小图跳过、失败回滚；热重载前确认正在处理的任务已结束。把 5.3 测试与 5.2 实机测试分别报告，不以 API 兼容写法代替实机结论。

## pond_bekkan 当前映射与参数

五个按钮在 Shader 面板纵向排列；上方是独立的“选中贴图生成 1K 副本”。下表数值是当前代码默认值，GUI 效果名称与 CLI ID 的关系来自用户看对照图后的选择，不表示官方提供了对应表。

| 按钮 | GUI 效果 | 经典版 CLI ID | 五参数默认值 | 证据边界 |
| --- | --- | ---: | --- | --- |
| Foto大块笔刷 | 油漆 4 | 12 | 20, 80, 25, 0, 30 | 用户确认 12 的笔触；保持当前参数 |
| Foto细条笔刷 | 油漆 7 | 25 | 100, 200, 20, 15, 50 | 25 看起来更像油漆 8，用户明确决定先作为 7；参数在 1024×1024 上试出 |
| Foto点画色块 | 油漆 9（水彩） | 17 | 9, 255, 13, 59, 10 | 用户确认 17 是大片平滑水彩；当前参数在 2K 可用 |
| Foto毛躁笔刷 | 油漆 10 | 26 | 50, 50, 50, 130, 130 | 用户根据笔触对照选择 26 |
| Foto混合笔刷 | 油漆 11 | 21 | 50, 300, 30, 5, 200 | 用户确认笔触；该组是 2K 基准参数 |

油漆 8 暂不提供按钮：独立准确编号未确认，用户明确选择等待。11 仅将前两项笔刷按“最长边 / 2048 × 额外倍率”换算，其余三项保持；额外倍率默认 1。例如 1K 实际调用 25, 150, 30, 5, 200。其余四项目前不做尺寸换算，等待用户提供 1K 最佳参数后再判断。超过外部程序笔刷上限时不能假定线性缩放仍有效，优先使用独立的 1K 副本流程。

本轮已在独立 Blender 5.3 环境核对 2048→1024、副本不改原文件 SHA-256 和 Image 尺寸、Vector/下游转接以及 <=1K 跳过；源码同步到 5.3 安装目录后在任务清空时热重载，读回五个预设和新按钮。5.2 尚未做本轮实机测试；系统提示音只检查了模块和调用可用性，未现场确认可听。用户场景未因这些验证而保存。历史试错和撤回判断见 pond_bekkan 的《2026-11-14-FotoSketcher贴图风格化》开发记录；使用前以当前仓库代码和程序版本为准。
