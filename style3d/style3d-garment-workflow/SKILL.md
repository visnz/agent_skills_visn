# Style3D 服装建模

目标是交付可继续编辑的 Style3D 工程，并让参考图、分件判断、模拟结果和未解决问题能逐一对应。尊重用户指定的部件范围与完成度；阶段收尾时保存检查点，不自动扩展到裙子、装饰或精修。

## 选择工作入口

- 连接本地 Style3D 前，读取 [连接方式](references/connection.md)，确认运行中的服务身份、当前工程和接口契约。优先使用已提供的 MCP 工具；需要 HTTP 辅助时才用 `scripts/style3d_rpc.ps1`。历史端口不是默认目标。
- 制作纸样、缝合和模拟时，按需读取 [制作与验证](references/authoring.md)。读取运行服务中所用 API 的完整 entry；案例调用不能代替当前版本文档。
- 单图、复杂层叠或角色服装，先对照参考标出贴身底衣、独立覆布、领片、带子、腰带、裙层和硬质辅料，记录层次与固定点。被遮挡部分标为推测，优先采纳用户的局部裁图和结构纠正。只在分件足够明确后打板；参考 [Hana 案例](references/hana-simulation-workflow.md)。
- 对图像转纸样工具，先核对输出是否保留关键分件和层次，再考虑面板数、几何合法性或导入模拟。简单衣服可以用作起稿；复杂参考需要人工确认分件。三图实测及版本边界见 [ChatGarment 案例](references/chatgarment-evaluation-2026-10-30.md)。这不是所有模型版本的性能结论。

## 制作与验收

1. 查询已有模特、服装及保存位置；重要改动另存，不覆盖用户工程。选择模板时说明来源；要求从零打板时建立原生纸样。
2. 先建立贴身底层，按身体部位检查胸腰贴合、前后片分配及侧缝，再加独立覆布和固定关系。面料外观参数与物理参数分别检查。静态摆出的形状须经实际模拟验证。
3. 结构变化后刷新实体 ID，检查纸样自交、缝合关系和模拟状态。把超时、开始运动、趋稳和正式收敛分别记录；异常时先查状态与摆放，再有限度补救。
4. 软布与硬件分开处理。外部建模的 OBJ 可作为固定道具导入；随衣物运动的连接须单独验证，不能由导入成功推断。参考 [Hana 案例](references/hana-simulation-workflow.md)。
5. 从真实 Style3D 快照检查正、背、侧面及局部贴合；保存 `.sproj` 和预览，注明冻结支撑件、未完成部件及检查局限。不要用手工塑形预览冒充模拟结果。

首次连接和模板试穿的已验证行为见 [T 恤案例](references/practice-tshirt-2026-10-30.md)。参考资料中的日期、路径、端口、面料值和耗时均为历史现场；新任务重新发现。Blender 可用于刚性件及模拟网格检查，具体 Blender 操作由相应 Blender 技能处理。
