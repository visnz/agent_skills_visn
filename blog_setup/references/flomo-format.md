# flomo 导出格式详解与案例

## 文件命名

- `YYYYMMDDHHMM_序号.md`，例如 `202610261945_1.md`。
- 本案例以前 12 位作为创建分钟；序号不作为稳定身份，同分钟多条在当前兼容命名下会冲突并停止，不假定导出永远不发生此情况。
- 生成的帖子文件名用前 12 位 `YYYYMMDDHHMM.md`。

## md 内容结构

```
【标题】（可选，全角方括号，通常在首行）
（正文，可能含列表、段落、图片引用）
#标签行（可能出现在正文中间或末尾，`#` 后无空格）
[日期 时间](https://flomoapp.com/mine/?memo_id=...)（末行原文链接）
```

## 清理规则（脚本已实现）

1. **标签行**：整行（strip 后）由 `#标签` 组成（`#` 后无空格，多个标签用 `#` 或空格连接），例如 `#思考#精选#索引/同步到网站`、`#感受和情绪/体验 #索引/同步到网站`。位置不固定（开头/中间/末尾）都要删。与 Markdown 标题 `# 标题`（`#` 后带空格）区分。

2. **原文链接**：末行独立的 `[日期](https://flomoapp.com/mine/?memo_id=...)` 删除；memo_id 用于同步身份。正文其他位置的链接保留。

3. **标题**：第一个非空行若匹配 `【...】`，提取为 `title` 并移除该行；没有则不写 `title`。

4. **图片**：简单内联图片指向的本地文件必须存在，可相对 memo 所在子目录定位。图片复制到 `source/assets/moment/<内容哈希>.<扩展名>`，正文与 photos 一致更新；不同来源的同名图片不互相覆盖。不支持的引用式/HTML 本地图片需先转换输入；原导出不修改。


标题和 photos 字符串用 JSON 双引号字符串写成 YAML 标量，避免冒号、井号和布尔值等被误解释。只认第一个非空行的【标题】，正文后续同样格式的行保留；标签删除和空行压缩是既有清洗规则，原 ZIP 应保留。格式是该 Markdown 导出方案的约定，不宣称支持任意 flomo 版本或 HTML 导出。
