## 已验证的阅读器改进

- 书签原文预览与备注分离；跨月按稳定 mid 定位，读取复用；保存用 POST 后 GET 回读确认，初始加载失败阻止空状态写回。HTTP 的硬盘文件与 file:// 的浏览器存储分开处理。
- 后续加入蓝色“回复”，复用黄色的多条、备注、编辑、删除和跳转逻辑，加入独立分组、总数、旧数据归一化和颜色样式。7 项内存检查覆盖新增／编辑／载荷／回读／独立删除及旧黄绿保留，页面确认了四个选项与空回复分组；没有向用户实际书签写临时测试项。
- 绿色排序检查使用现有 23 条记录，确认原聊天时间决定顺序；某条后添加的早期消息确实编号更早。代码仅在聊天时间相同后使用添加时间兜底，未验证同秒消息与原时间线顺序完全一致。
- 微信／Telegram 共 14,994 条聊天的统计与新增社交内容分离；微博／小红书独立显示开关能跨月、刷新保留，关闭微博后旧聊天仍显示，重新开启可见；小红书仅验证开关状态，未有真实小红书数据。
- 搜索索引含 13,447 条有已有文本的聊天（低于总条数不代表遗漏所有无文本媒体）。历史页面验证了跨月份关键词、来源／发送人筛选、50→100 条分批显示、无匹配提示、点击锚点／高亮与返回筛选；所有索引 ID 在合并 HTML 找到，7 项内存检查包含字面标点和 HTML 安全高亮。

## 反例：新页面出现但搜索完全没启动

**观察**：用户 Chrome 的 URL 已带关键词，索引变量已有 13,447 条，但输入为空、状态栏空白、工具栏没有新搜索入口。用同页面正常读取不缓存的脚本时，服务响应里已存在搜索函数；另一测试浏览器此前能正常搜索。

**修复与验收**：为 app.js、CSS、索引加入生成器／内容相关版本参数，并同步所有层级页面及后续重建路径。直接刷新用户出问题的 Chrome 后，同一关键词显示 2 条结果，输入回填与搜索入口出现。根因判断有“原浏览器旧功能标记＋服务新脚本＋刷新后生效”的对照支持；不能把所有零结果都归为缓存。

**下次先检查**：实际关键词／筛选、加载版本和显式状态。不要要求用户重新输入很多词，或只在新浏览器测通就结束。

## 局部有效：微博正文、转发与媒体

- 顶层作者身份过滤后，11 次已保存分页得到 208 个唯一动态：78 原创、130 转发；原始唯一数与导入数一致，未发现导入阶段丢失这些转发。过滤掉的是其他账号插入项；普通转发也可能 isAd=true。
- 主页／响应总数为 1728；第 11 次分页明确返回“更多内容请至客户端查看”，后续游标为空。网页实际底部也读到该提示，任务暂停。与主页差额为 1520，只是数量差，未证明差额都在最早已抓日期之前，也未证明可正常访问的历史数恰为主页总数。
- 已保存范围为 2018-03 至 2024-10，并不等于该区间每条都覆盖；不能只因出现很早日期就称已抓全。反过来，页尾提示也不能证明电脑年份筛选／搜索一定无效。
- 现场主页／长文作业采用 45 秒间隔、每批最多 6 条（页），下载媒体间隔 2 秒，遇 429／服务器异常或连续三次失败即暂停。这些是该次配置，不是对平台风控的保证。
- 媒体清单报告 1,061 项 complete：1,033 正文图片、13 视频封面、15 视频；对应有限媒体任务 finished。旧交接仍有“后台补媒体”描述，属于过时运行状态，不能继续报告仍在下载。
- 全文目标 58 个，已导出 9 个响应，其中 8 个非空正文、1 个 HTTP 200／ok=1 但空 data。经核对将该条标为暂不可获取并保留节选，避免空响应覆盖旧全文；49 个仍待补。旧浏览器 helper 已暂停，磁盘最新版 helper 与其状态不一致，恢复前需核实旧任务停止并迁移断点。
- 小红书只预留颜色与开关，未采集，也未创建月更任务；评论仍未完成。账号 Cookie 未用于媒体下载。

**重试前提**：先读报告／断点与 helper 版本，选一个正常入口和可对照的漏项小样本，核对新获得的可见范围；遇正常验证交用户处理。没有新依据不强翻空游标、不并行重复 watcher、不把源码队列总数照搬到新范围。

## 未开始提取：模拟器与桌面控制

- BlueStacks 5 经官方资料调研后由用户安装，已发现其窗口，但只读到外层未命名控件；多次截图出现 FrameArrived／window capture timeout。按用户最大化前台、重新绑定与重置控制连接后仍失败，停止接管，没有盲点。
- 之前 Chrome 原生截图也出现同类故障，所以“桌面截图通道有问题”只是合理怀疑，并非已定位到系统组件的根因。
- 未在模拟器内验证微博登录、结构化读取、原图／视频导出或任何批量采集。不是“微博提取失败”，也不是“客户端路线不可行”；仅证明当时控制链路未可用。
- 用户后来确认手机正常可见不等于 Agent 已能提取。少量原创、转发、多图／视频样本测试是拟议验收，不是已经执行的结果。

**再探索条件**：有可用且经授权的画面／文本读取能力，先验收一个样本从显示到本地文本和媒体完整保存，再扩展；仍读不到时停止。没有新工具条件不要再次要求用户重装或来回最大化。

- 该环境中使用文件读写工具能完成当前可写目录内的代码／文档编辑；不据此推断可以绕过终端、网络或其他目录的拒绝。程序启动失败与程序执行结果应分开。
