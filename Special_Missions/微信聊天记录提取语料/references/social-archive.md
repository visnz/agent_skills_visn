# 向聊天归档接入社交来源

只用于围绕同一聊天归档的额外来源接入。先确认用户授权的账号、原创／转发／点赞／评论范围和媒体目标；上下文已经明确时直接遵循，不重复问。

## 保持独立来源与聊天不变量

- 每个来源独立保存分页原始响应、规范化 posts、媒体清单、报告和断点；展示合并是派生结果，不把来源原始数据直接混写进聊天原始库。
- 使用 source、kind、原生帖子 ID 与稳定 archive_id 标识，例如 source-原生ID；以本人的发表／转发时间进入时间线，引用原文保留原作者、原时间、正文与媒体。
- 导入时按目标账号的顶层作者身份筛选，区分推荐插入与本人动态；保留嵌套转发原文。不要把 isAd 一类展示标记当作作者身份或转发过滤条件：本案例的普通转发也出现过 true。
- 合并按稳定排序和原生 ID 去重，可重复执行；验证原聊天内容／相对顺序／稳定锚点、阅读状态与已存在的其他来源不变。
- 把独立来源重合并接入预处理／重建入口；缺少已声明必需的来源文件时明确报错，避免重建后静默消失。
- 正文、作者、链接、媒体路径均作安全处理：转义文本，限制链接协议和本地媒体根目录，拒绝绝对路径、反斜杠及 .. 穿越；不要直接执行响应中的 HTML。

## 展示、开关与统计分别定义

- 本阅读器约定微博浅黄色、小红书浅红色；转发引用嵌在同一动态卡片内。颜色不是站点通用规则。
- 合并时间线为微博、小红书提供独立开关，偏好记在浏览器；明确默认值、翻月／刷新行为及只隐藏展示的语义，单独来源存档不受影响。
- 关闭来源时暂停其视频；切换时锚定可见消息减少跳动。书签或直接锚点定位到被过滤来源时重新显示该来源，避免“跳到但看不见”。
- 本用户要求统计仅计微信／Telegram 聊天。消息数、图片／视频数、字数、趋势、峰值与聊天月份口径一并排除社交内容；切换来源开关不影响这些统计。
- 区分首页时间线包含的月份和有聊天记录的月份，不把只有社交动态的月份计入聊天趋势。

## 有限抓取与完整性报告

- 优先沿用已授权的正常访问入口，以小批量、保守间隔读取；每页／每条先落盘或持久化断点，再进入下一步。间隔和批大小是现场参数，不能承诺某个数值一定不触发风控。
- 登录、验证码、访问频繁、重定向、非预期状态或响应结构变化时暂停，按正常流程交用户处理。不要切账号／代理、伪造客户端或强翻空游标去绕过限制。
- 导出后核对原始唯一 ID 数、过滤理由、规范化数量与时间范围；分别统计原创和转发。分页请求次数不能直接等同于 UI 滚动页数或主页全部数量。
- 主页总数、已抓取数、媒体完成度、全文完成度分开报告。到页尾不等于历史完整；返回“更多内容请至客户端查看”和空游标时记录证据与停止点，不把差额全归因于更早年份。
- 若需尝试年份筛选、另一版网页或客户端，先验证正常可见范围与真实模式，不把 UI 入口不同说成必须换电脑／手机或归档必须迁移。
- 当前浏览器 helper 的状态、断点库与本地最新源码可能不同。恢复前确认旧任务没有运行，检查版本和已保存记录；不要让两个作业同时抓同一队列。

## 正文与媒体补全

- 长文要检查非空正文；HTTP 200、ok=1 但 data 为空不能计为全文成功。仅在人工核对是内容缺失、没有风控信号后，将该项标不可获取并保留节选；不要把所有空响应一概当作同一原因。
- 新的空／不可用结果不得覆盖已经保存的全文；保留抓取状态和可见节选。转发原文也要进全文队列，原作者限制或删除时保留已知来源和不可见状态。
- 从实际响应提供的候选里选清晰可用图片及完整视频地址；封面和正文图片分开统计。媒体成功以本地文件、解码／探测、尺寸与摘要为准，不以取得 URL 为准。
- 用内容 SHA-256 去重存储，保留来源 URL、格式、尺寸、下载状态及视频封面关系。检查签名地址有效期；过期时不盲目请求，待正常读取更新后的地址。
- 能直接访问媒体地址时不附带账号 Cookie。遇 429／服务器异常或连续失败达到现场阈值时暂停，不做无上限重试；不要打印凭据、签名或登录数据。
- 导入、刷新与下载若写同一份媒体清单，实行单写者／锁；完成一个阶段再进入下一个。持久化每条结果，退出时释放自己的锁；旧 PID 或锁存在本身不等于作业仍活动，不擅删活动锁。
- 有限后台任务需要 finished／paused／failed、当前阶段、最后结果和待补队列。watcher 要区分旧导出与新导出，避免反复导入；不要把旧脚本硬编码的队列总数带到扩展后的范围。

## 客户端与重试边界

- 安装模拟器、能打开 App、能操作界面、能提取结构化文字、能取得原图／完整视频是不同验收点，不相互替代。
- 在要求用户安装或登录前说明当前工具能力与不确定性；先以原创、转发、多图／视频的少量样本确认端到端结果，再评估批量成本，不把安装本身当成已成立的采集方案。
- 桌面截图超时或只暴露未命名控件时按当前工具支持的恢复流程有限重连，不盲点。该故障不能证明 App 拒绝导出，也不能证明模拟器路线不可行。
- 没有新输入／工具条件／读取方法时，不重复让用户最大化、重装或原样试同一失败路线。需要重试时先读 [旧案例](2026-11-reader-extension-case.md)，说明新的验证目标及停止标准。

## 本流程的能力边界

这是按需操作流程，不是附带完整社交爬虫发行包。项目实现文件如 weibo_archive.py、merge_social.py、social_timeline.py、浏览器 helper 与作业脚本应在原归档内先读源码再使用；本技能目录未复制这些账号／目录专用文件。小红书若只接好了展示字段与样式，应写“预留接入”，不能写成已完成采集或月更自动化。
